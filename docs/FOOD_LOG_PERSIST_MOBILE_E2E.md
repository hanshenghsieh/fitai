## A · 基本記錄 → 切 tab → 回來

1. 打開 **今日**（`/dashboard`）
2. 點底部 **＋ 記錄** → **文字記錄**
3. 搜尋 **茶葉蛋** → 選第一個結果 → 確認記錄
4. 確認首屏今日飲食列表有 **茶葉蛋**
5. 切到 **進步** tab，等 2 秒
6. 切回 **今日** tab
7. **預期**：茶葉蛋仍在列表，熱量加總未歸零

| 結果 | ✓ / ✗ | 備註 |
|------|-------|------|
| 切 tab 後仍在 | | |

## B · 記錄 → 完全關閉 App → 重開

1. 再記一筆 **雞胸肉**（或任意 P0 食材）
2. **完全滑掉 App**（不是只按 Home）
3. 等 5 秒，重新打開 BetterBit
4. 進入 **今日**

## C · 刪除後持久化

2. 切到 **本週** → 回到 **今日**
3. 完全關閉 App → 重開

## D · 弱網 / 飛航模式（選做）

1. 開啟 **飛航模式**
2. 記一筆 **地瓜**
3. **預期**：頂部顯示「離線模式」橫幅（非全屏封鎖），今日列表仍顯示上次同步的紀錄
4. 關閉飛航模式，等 10 秒或切 tab 一次
5. 完全關閉 App → 重開

| 結果 | ✓ / ✗ | 備註 |
|------|-------|------|
